# RCA News SPFx

Custom SharePoint Online News web part styled for the RCA site.

## Target
- SPFx 1.23.2
- Node.js 22 LTS
- React 17.0.1
- SharePoint Online

## Experience
- Featured newest SharePoint News story
- Responsive news-card grid
- RCA red / warm gold / burgundy visual language
- Uses current site's Site Pages library
- Optional category filter
- Configurable title, intro, and item count

## Setup
Create a current SPFx 1.23.2 React web-part scaffold named `RcaNews`, then replace its
`src/webparts/rcaNews` folder with this repository's folder.

Use the current Microsoft SPFx CLI and verify its available create flags with:
`npx @microsoft/sharepoint-cli create --help`

Then install, build, and package using the scripts generated by the 1.23.2 scaffold.

The deployable `.sppkg` is produced in the scaffold's `sharepoint/solution` output.
Upload that package to your SharePoint tenant App Catalog, deploy it, and add **RCA News**
to a modern page.

## Data
The component queries the current site's `Site Pages` list and filters to
`PromotedState eq 2` (SharePoint News). No custom service is required.

## Theme tokens
- RCA red `#C62828`
- Gold `#D9A51A`
- Burgundy `#6E1738`
- Warm canvas `#F7F5F0`
- Ink `#252525`

These are intentionally centralized in `RcaNews.module.scss`.
